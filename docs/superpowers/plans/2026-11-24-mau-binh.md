# Mậu Binh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a Vietnamese 1-human-vs-3-AI Mậu Binh web game (Vite + TypeScript) with 13-warriors-style chi scoring, additive So Át/Hai bonuses, four difficulty levels, and Vercel static deploy.

**Architecture:** Pure `src/core` rules engine (cards, waves, specials, pairwise scoring, So Át) tested with Vitest; `src/ai` HandOptimizer with handicap; thin `src/ui` + `main` for round lifecycle; Vite builds static `dist/` for Vercel.

**Tech Stack:** Vite, TypeScript, Vitest, vanilla DOM (no React), Vercel static hosting.

**Spec:** `docs/superpowers/specs/2026-11-24-mau-binh-design.md`

## Global Constraints

- UI copy: Vietnamese only  
- Players: 1 human + 3 bots; no online multiplayer in MVP  
- Reference only: [macroxue/13-warriors](https://github.com/macroxue/13-warriors) — reimplement, do not fork UI/assets wholesale  
- Suit order for So Át/Hai: Hearts > Diamonds > Clubs > Spades  
- So Át points: Nhất 30, Nhì 20, Ba 10, Bét 0 (additive on `chiScore`)  
- Difficulty UI names: Jô / Đầm / Già / Át with handicaps 6 / 4 / 2 / 0  
- All project files under `/Volumes/WD 1TB/Projects/24. Dự án game bài Mậu Binh`  
- Prefer small pure modules; YAGNI  

## Review Focus

- Four seats with identical Ace counts and identical strongest Ace suits → even split of occupied So Át ranks must sum to 60  
- Folded seat: `chiScore === 0`, excluded from chi pairs, still receives So Át from dealt hand  
- Bot at every difficulty must never submit Front > Middle or Middle > Back (foul)  
- Special claim (Dragon / Six Pairs / Three Flushes / Three Straights) awards reference points and skips normal chi compare for that seat vs others as defined in Task 5  
- Peek / auto / fold / claim buttons must match level flags exactly (Át disables peek+auto+claim_aid)

### Task 5: Pairwise chi scoring + fold

**Files:**
- Create: `src/core/scoring.ts`
- Test: `tests/core/scoring.test.ts`

**Interfaces:**
- Consumes: `evaluateChi`, `compareChi`, `PATTERN_POINTS`, `detectSpecial`  
- Produces:
  - `type SeatArrangement = { front: Card[]; middle: Card[]; back: Card[]; folded?: boolean; specialKind?: SpecialKind }`
  - `function scoreRoundChi(seats: SeatArrangement[]): number[]` // length 4, net `chiScore` per seat

**Rules to encode (from spec):**
- Skip folded seats in pairwise chi; folded seat `chiScore = 0`  
- For each unordered pair of non-folded seats, for each chi: winner gets `PATTERN_POINTS[chi][winner.pattern]`, loser loses same  
- If one seat wins all 3 chis vs another: double that pair’s chi points (scoop ×2 like reference)  
- If seat claims special (`specialKind > 0`): that seat does not play normal chis; instead each other non-folded seat pays `SPECIAL_POINTS[kind]` to the claimant (and claimant does not pairwise-compare chis). If two seats both special, compare `SPECIAL_POINTS` / kind order Dragon > SixPairs > ThreeFlushes > ThreeStraights — loser pays winner the difference of points (document choice in test).  

- [ ] **Step 1: Failing tests**
  - Two seats only active: stronger back pair transfers back points  
  - Scoop doubles  
  - Folded seat stays 0 while others score  
  - Review Focus: folded seat still later gets So Át in Task 6 integration test  

- [ ] **Step 2–4: Implement + PASS**

### Task 6: So Át / So Hai

**Files:**
- Create: `src/core/so-at.ts`
- Test: `tests/core/so-at.test.ts`

**Interfaces:**
- Produces:
  - `const SO_AT_POINTS = [30, 20, 10, 0]`
  - `function scoreSoAt(hands: Card[][]): number[]` // length 4 bonuses

**Algorithm (spec verbatim):**
1. Rank by Ace count desc  
2. Tie with count > 0: strongest Ace suit only (♥>♦>♣>♠)  
3. Remaining group all 0 Aces: So Hai (Two count, then strongest Two suit)  
4. Residual ties: split evenly points of occupied ranks (sum of those rank pots / n)  

- [ ] **Step 1: Failing tests**
  - Unique Ace counts → 30/20/10/0 by count  
  - Two players 1 Ace: Hearts Ace beats Spades Ace  
  - Top two have 2 Aces each; bottom two 0 Aces → bottom ranked by Hai  
  - Review Focus: four-way identical → each gets 15 (60/4)  

- [ ] **Step 2–4: Implement + PASS**
